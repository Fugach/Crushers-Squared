# Крушители²
Моя игра на Godot, изначально сделанная для школьного проекта.
### Сборка
1. Скачайте последнюю версию [Godot Engine](https://godotengine.org/download)
> [!NOTE]  
> В случае появляения каких-либо неожиданных багов в скомпилированной игре (например, присутствие багов, которых нет в моих сборках, или игра вообще крашится), то попробуйте версию Godot Engine 4.7.1 (https://godotengine.org/download/archive/4.7.1-stable). Это может помочь, так как именно на этой версии я сейчас сижу. Либо вы скачали исходник с коммитами, которых ещё нет в последнем релизе ¯\\\_('-')_/¯.
2. Скачайте исходник
- ``git clone https://github.com/Fugach/Crashers-Squared``

  либо
- Сверху зелёная кнопка "Code" -> "Download ZIP" -> распаковать архив куда вам удобно
3. Запустите Godot Engine -> сверху кнопка "импорт"/"import" -> дошагайте до папки с исходником (в этой папке должен быть файл ``project.godot``!!!) -> снизу кнопка "Выбрать эту папку"/"Choose this folder"
4. Следуйте инструкциям на экране. В списке проектов появится мой проект.
5. Двойной клик ЛКМ по проекту или справа кнопка "Редактировать"/"Edit"
6. Откроется редактор -> сверху кнопка "Проект"/"Project" -> "Экспортировать..."/"Export..."
7. В открывшемся окне выберите предустановку для нужной системы, напишите имя исполняемому файлу и нажмите внизу окна "Экспортировать проект..."/"Export project..."
> [!TIP]
> Если вы только скачали Godot и ничего с ним не делали, то, вероятно, вылезет ошибка об отсутствии компилятора для нужной вам платформы. Просто следуйте инструкциям в ошибке или воспользуйтесь [официальной документацией Godot Engine](https://docs.godotengine.org/en/stable/tutorials/export/index.html) для ознакомления.
8. Выберите папку и всё! Запускаемый файл игры готов!

> [!TIP]
> Некоторые GPU не поддерживают Vulkan. Однако вам никто не мешает изменить движок рендера на OpenGL, но стоит учитывать, что графика станет хуже, а производительность может разительно изменится в зависимости от вашего процессора, видеокарты и ваших драйверов на неё. Если при попытке открытия проекта в редакторе происходит вылет, то попробуйте запустить движок с параметром ``--rendering-driver opengl3 `` в командной строке или терминале.
